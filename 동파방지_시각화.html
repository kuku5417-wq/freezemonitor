1. 추진 배경 및 목적

배경

조선소 야드·선박 엔진룸 내 배관은 동절기 동파 위험에 상시 노출되어 있다. 현재는 운전원이 주기적으로 현장을 순시하여 온도를 확인하고 순환펌프를 수동 기동하는 방식으로 운영 중이며, 야간·무인 상황에서의 대응이 늦을 경우 배관 동파·누수 사고로 이어질 수 있다.

목적

구분내용
1차 목적엔진룸 기온 자동 감시 → 설정 온도 이하 시 순환펌프 자동 기동
2차 목적온도·펌프 운전 상태 실시간 대시보드 표시 및 카카오 오픈채팅 경보 발송
파일럿 목적실제 현장에 1세트 설치·시운전하여 동작 검증, 양산·확대 적용 여부 판단

적용 방식 — 3안: 로컬 스타터반 직결

  • TK4S OUT1 접점 → 로컬 스타터반 Remote Start 단자 직결 (ER 내 완결)
  • 사외망 WiFi로 Modbus 데이터 수집 + 카카오 오픈채팅 경보
  • P-LTE·ECR LAN I/O 불필요 → 최저 비용, 최고 안정성

엔진룸 온도 급변으로 잦은 기동저낮음HYS 값 조정 (예: 5/10℃로 확대)

7. 성공 기준

아래 기준을 모두 충족하면 양산·확대 적용 단계로 진행한다.

  • 엔진룸 기온 연속 7일 이상 정상 수집 (통신 두절 없음)
  • 설정 온도 이하 시 순환펌프 자동 기동 1회 이상 실동작 확인
  • 경보 발생 시 카카오 오픈채팅 알림 4명 전원 수신 확인
  • 사외망 단절 상황에서도 펌프 기동/정지 정상 동작 확인
  • 운전원 교육 후 대시보드·알림 운용 가능 수준 확인
